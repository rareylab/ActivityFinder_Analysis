# LaTeX Table Usage Guide

This document explains how to use the LaTeX tables generated by the HET code variants analysis.

## Generated Table Format

The analysis generates a `.tex` file containing a publication-ready multipage LaTeX table with the complete distribution data. The table shows:

- **Number of variants**: Individual variant counts (1, 2, 3, ...)
- **Number of HET codes**: Count of HET codes with that many variants (formatted with `\num{}`)
- **Percentage**: Percentage of total HET codes

The table uses `longtable` format to automatically span multiple pages when needed.

## Basic Usage

Include the generated table in your LaTeX document:

```latex
\documentclass{article}
\usepackage{booktabs}   % Required for \toprule, \midrule, \bottomrule
\usepackage{longtable}  % Required for multipage tables
\usepackage{siunitx}    % Required for \num{} number formatting

\begin{document}

\input{variants_per_het_code_table.tex}

\end{document}
```

## Number Formatting

All numbers in the "Number of HET codes" column are formatted using siunitx for enhanced readability:

```latex
26 & \num{1} & 0.003 \\
27 & \num{3} & 0.008 \\
```

This provides proper spacing and alignment for large numbers.

## Required LaTeX Packages

**All packages are required**:
```latex
\usepackage{booktabs}   % Professional table rules

```

## Customization

### Table Caption and Label
The generated table includes:
- **Caption**: "Distribution of HET Codes by Number of Variants"
- **Label**: `tab:het_code_variant_distribution`

Reference the table in your text:
```latex
As shown in Table~\ref{tab:het_code_variant_distribution}, most HET codes have few variants.
```

### Column Alignment
The table uses `{rrr}` alignment (right-aligned columns). Modify the generated `.tex` file if needed:
- `{lll}` for left-aligned
- `{ccc}` for center-aligned
- `{lcr}` for mixed alignment

### Multipage Features
The generated table automatically handles page breaks with:
- **First page header**: Full table header with caption
- **Continuation headers**: "Continued from previous page" notice
- **Page footers**: "Continued on next page" notice
- **Final footer**: Clean bottom rule on last page

## Troubleshooting

### "Undefined control sequence \num"
**Problem**: LaTeX doesn't recognize `\num{}` command.

**Solution**: Add `\usepackage{siunitx}` to your preamble. This package is required for all generated tables.

### "Undefined control sequence \toprule"
**Problem**: LaTeX doesn't recognize booktabs commands.

**Solution**: Add `\usepackage{booktabs}` to your preamble.

### "Undefined control sequence \longtable"
**Problem**: LaTeX doesn't recognize longtable environment.

**Solution**: Add `\usepackage{longtable}` to your preamble. This package is required for all generated tables.

### Table appears cut off
**Problem**: Table doesn't fit on a single page.

**Solution**: The generated table uses `longtable` which automatically handles page breaks. Ensure you have `\usepackage{longtable}` in your preamble.

## CLI Integration

The table is automatically generated when using:

```bash
# Generate table with plots
actfind plot-het-code-variants --generate-latex

# Generate only the table
actfind plot-het-code-variants --no-create-plots --generate-latex

# Or using justfile
just latex-only
```

All tables are generated with multipage longtable format and siunitx number formatting.
